🖥️ MATERI A

Antarmuka Pengguna

Antarmuka pengguna (user interface) adalah tampilan yang menjadi penghubung antara manusia dengan komputer, sehingga kita dapat memberi perintah dan menerima hasil dari komputer.

Antarmuka Grafis (GUI)

Sebagian besar komputer dan gawai sekarang menggunakan GUI (Graphical User Interface) — antarmuka berbasis gambar, ikon, dan jendela yang membuat kita lebih mudah berinteraksi tanpa perlu mengetik perintah rumit.

Contoh: layar utama (home screen) HP kalian dengan ikon-ikon aplikasi adalah salah satu bentuk GUI.

Bagian-bagian Antarmuka

Ikon

Gambar kecil yang mewakili aplikasi, file, atau folder.

Menu

Daftar pilihan perintah yang dapat dipilih pengguna.

Jendela (Window)

Area tampilan tempat aplikasi berjalan.

Kursor / Pointer

Penunjuk yang bergerak mengikuti mouse atau sentuhan jari.

Cara Berinteraksi dengan Antarmuka

Klik

Menekan tombol mouse/trackpad untuk memilih.

Klik ganda

Membuka aplikasi atau file dengan cepat.

Seret (Drag)

Memindahkan ikon atau jendela ke tempat lain.

Gulir (Scroll)

Menggeser tampilan ke atas/bawah untuk melihat isi lain.

📁 MATERI B

Folder, File, dan Ekstensi File

File adalah data atau informasi yang disimpan pada komputer, seperti dokumen, gambar, atau video. Folder adalah tempat menyimpan sekumpulan file agar lebih rapi dan mudah ditemukan.

Contoh Struktur Folder

Klik folder untuk membuka/menutup isinya:

  • Sekolah
    • Informatika
      • Tugas
        • tugas_bab3.docx
      • Materi
        • ringkasan_bab3.pdf
      • Presentasi
        • project_digital_office.pptx

Folder Sekolah → subfolder Informatika → subfolder Tugas / Materi / Presentasi → berisi file.

Ekstensi File

Ekstensi adalah bagian akhir nama file yang menunjukkan jenis/format file tersebut.

EkstensiJenis File
.docxDokumen pengolah kata
.pptxBerkas presentasi
.xlsxBerkas spreadsheet
.pdfDokumen portabel
.jpg / .pngBerkas gambar
.mp4Berkas video
Tips Mengorganisasikan File Agar Rapi

Beri nama file yang jelas, kelompokkan file sejenis dalam satu folder, dan buat subfolder berdasarkan mata pelajaran atau jenis tugas — seperti contoh struktur folder di atas.

🌐 MATERI C

Peramban & Search Engine

Peramban (browser) adalah aplikasi untuk menjelajahi halaman web. Search engine (mesin pencari) adalah layanan di dalam browser yang membantu kita menemukan informasi menggunakan kata kunci.

Fungsi Browser

Membuka dan menampilkan halaman web, seperti Chrome, Firefox, atau Edge.

Fungsi Search Engine

Mencari informasi di seluruh internet berdasarkan kata kunci yang kita ketik.

Simulasi Pencarian

Coba ketik "komputer", lalu bandingkan dengan kata kunci yang lebih spesifik seperti "komputer generasi kelima".

Tips Kata Kunci
  • Gunakan kata kunci spesifik agar hasil lebih relevan.
  • Hindari kata kunci yang terlalu umum/luas.
  • Gunakan beberapa kata kunci berbeda jika hasil belum sesuai.

Jangan langsung percaya semua hasil pencarian! Selalu periksa sumber informasi sebelum menggunakannya.

✉️ MATERI D

Surel / Email

Surel (surat elektronik) adalah pesan yang dikirim secara digital melalui internet. Surel banyak digunakan untuk komunikasi resmi di sekolah maupun dunia kerja.

Kepada / To

Alamat email tujuan penerima pesan.

Subjek / Subject

Ringkasan singkat mengenai isi pesan.

Isi Pesan

Uraian lengkap yang ingin disampaikan.

Lampiran

Berkas tambahan seperti foto atau dokumen.

Etika Berkirim Surel

Gunakan subjek yang jelas, bahasa sopan, salam pembuka/penutup, dan periksa kembali sebelum mengirim.

📝 MATERI E

Aplikasi Perkantoran

Aplikasi pengolah kata (word processing) digunakan untuk membuat berbagai dokumen digital yang rapi dan mudah dibaca.

Dokumen

Catatan atau tulisan digital sederhana.

Laporan

Dokumen berisi hasil kegiatan/pengamatan.

Surat

Dokumen resmi dengan format baku.

Brosur Sederhana

Media promosi/informasi ringkas bergambar.
